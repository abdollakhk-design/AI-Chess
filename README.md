# AI-Chess

«AI-Chess» — пайдаланушы деңгейіне қарай бейімделетін, машиналық оқыту элементтері бар интеллектуалды шахмат ойыны.

## Жобаның мақсаты

- Шахматты үйренушілерге және тәжірибелі ойыншыларға арналған ойын.
- Ойыншы жеңіске жеткен сайын жүйе ойын деңгейін арттырады, ал жеңілгенде жеңілдете түседі.
- Қарапайым `pygame` интерфейсі және шахмат ережелерін басқару үшін `python-chess` кітапханасы.

## Негізгі функциялар

- Қолданушы үшін 3 деңгей:
  - Beginner — кездейсоқ жүрістер.
  - Intermediate — қарапайым бағалау.
  - Advanced — minimax іздеу.
- Ұпай негізі және динамикалық адаптация: ойыншы жеңген сайын қиындық авто-өрлейді.
- Жүйе ойын нәтижелерін `performance.json` файлына сақтап, келесі сеанста деңгейді бейімдейді.

## Қалай іске қосамыз

1. Жоба папкасына кіріңіз:
   ```bash
   cd ~/Desktop/python.py/ai_chess
   ```
2. Қажетті тәуелділіктерді орнатыңыз:
   ```bash
   python3 -m pip install -r requirements.txt
   ```
3. Ойынды бастаңыз:
   ```bash
   python3 main.py
   ```

- Немесе `start_game.command` файлын екі рет басыңыз.
- Негізгі папкадан іске қосқыңыз келсе, `AI-Chess Start.command` файлын екі рет басуға болады.

## Басқару

- Тінтуірмен фигураны басыңыз.
- Бірінші шерту — фигура таңдау.
- Екінші шерту — мақсатты ұяшықты таңдау.
- `R` — ойынды қайта бастау.
- `ESC` — шығу.

## GitHub-қа орналастыру

1. Жаңа репозиторий жасаңыз GitHub-та.
2. Жергілікті репозиторийде:
   ```bash
   git remote add origin https://github.com/USER/AI-Chess.git
   git branch -M main
   git add ai_chess "AI-Chess Start.command" .gitignore
   git commit -m "Add AI-Chess project"
   git push -u origin main
   ```

## Жоба файлдары

- `main.py` — ойын терезесі, шахмат тақтасы, басқару және статистика логикасы.
- `ai_agent.py` — AI деңгейлері, бағалау функциясы және minimax алгоритмі.
- `requirements.txt` — қажетті Python кітапханалары.
- `case_study.md` — жобаның қысқаша оқу-кейс сипаттамасы.
- `start_game.command` — macOS-та ойынды екі рет басып іске қосу файлы.
